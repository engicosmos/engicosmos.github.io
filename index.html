Engineering physics of space, explained.

How heat shields survive reentry, why rockets shake, how telescopes stay cold. Short, accurate explanations built on real engineering.

The channel

EngiCosmos is an English-language YouTube channel about spacecraft, rockets, satellites, telescopes and the physics behind them. Every script is checked by an engineer before it is published. Watch it at youtube.com/@engicosmos.

EngiCosmos Studio

EngiCosmos Studio is the internal tool the channel uses to publish its own videos. It is not a public service and it has no sign-up: it is used only by the channel owner, on the owner's own computer, for the EngiCosmos channel.

When the owner approves a finished video, EngiCosmos Studio uses the YouTube Data API (YouTube API Services) to upload that video and its thumbnail to the EngiCosmos channel, with the title, description, tags and publishing time the owner chose.

It does not read, collect or store information about viewers or any other YouTube users, and it does not access any channel other than EngiCosmos. Details are in the privacy policy. Use of the tool is subject to the terms of use, which include the YouTube Terms of Service.

YouTube API Services

EngiCosmos Studio uses YouTube API Services (YouTube Data API v3) to upload approved videos and thumbnails to the EngiCosmos YouTube channel. It requests only the youtube.upload permission.
